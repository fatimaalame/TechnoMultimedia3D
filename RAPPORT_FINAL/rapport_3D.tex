\section{Modélisation 3D -- Train des Aventuriers du Rail}

\subsection{Description}

L'objet modélisé est un petit wagon inspiré du jeu \textit{Les Aventuriers du Rail}. Le modèle reprend le style simplifié des pions du jeu avec une géométrie volontairement simple afin de faciliter l'impression 3D.

La modélisation a été réalisée entièrement avec \textbf{OpenSCAD} en utilisant une approche paramétrique.

\subsection{Paramètres}

Le modèle possède plusieurs paramètres permettant de modifier sa forme :

\begin{itemize}
\item \textbf{L} : longueur du wagon
\item \textbf{W} : largeur du wagon
\item \textbf{H} : hauteur du wagon
\item \textbf{detail} : niveau de détail du modèle
\end{itemize}

Ces paramètres peuvent être modifiés directement dans OpenSCAD via le panneau de personnalisation.

\subsection{Niveaux de détail}

Le modèle propose trois niveaux de détail :

\begin{itemize}
\item Niveau 1 : structure de base (corps principal, toit arrondi et roues)
\item Niveau 2 : ajout des fenêtres sur les deux côtés du wagon
\item Niveau 3 : ajout de marchepieds décoratifs
\end{itemize}

Le niveau le plus détaillé est destiné à l'impression 3D.

\subsection{Choix de conception}

Le modèle a été conçu avec des formes simples (cubes et cylindres) afin de conserver un code lisible et facilement modifiable. L'objectif était d'obtenir un objet reconnaissable tout en restant compatible avec une première approche de la modélisation paramétrique sous OpenSCAD.
